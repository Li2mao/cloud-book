# 多人联机坦克大战部署

## 用AI写出一个多人联机游戏

- 使用一个AI开发工具，VScode,Trae都可以
- 创建一个项目文件夹并且编写md文件

```XML
# 多人联机坦克大战游戏

- 技术栈，flask + websocket + html5 canvas
- 实现多人访问网页，可以在一个较大的，并且有随机掩体的地图中互相移动攻击
- 需要有多种道具可以增加玩家的能力
- 需要有排名功能，玩家可以根据自己的成绩和排名进行比较
- 需要有小地图，可以标注玩家的位置和移动方向
```

- 将自己的`需求.md`文件拖入对话框

```XML
实现这个代码，使用python虚拟环境，pip安装包需要清华源，规划好开发步骤，建立智能体小组，并发进行开发测试任务
```

## 将写好的文件传入linux服务器

* 创建并进入一个项目的文件夹`/opt/tank`

* 将做好的游戏打包进tank文件夹内，在`/opt`下编辑Dockerfile文件

  ```bash
  FROM python:3.12.0	# 安装python环境，提前pull好python镜像
  
  ADD tank /opt/tank	# ADD添加tank文件，ADD会自动解压里面的内容，COPY则不会。最好还是解压一下
  
  WORKDIR /opt/tank	# 指定工作的目录，以后的指令都会在此目录下工作
  # 这里的requirements.txt文件是AI生成之后产生的，里面存在的是运行程序需要的依赖
  RUN pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple	# 切换清华源
  
  EXPOSE 5000	# 开放5000端口，具体开放什么端口，可以查看文件或者问AI
  
  CMD ["python3","app.py"]	# python运行的游戏需要先执行python，然后再运行启动文件
  ```

* 启动Dockerfile搭建镜像`docker build -t tank:v1 .`

* 最后启动容器`docker run -d -p 5000:5000 tank:v1`

* 保存镜像`docker save -o 镜像.tar 镜像:版本号`
