## 相关知识解读

### Redis

Redis 是开源、内存型 KV 数据库，C 语言开发，速度快；支持持久化（RDB/AOF），可做缓存、分布式锁、计数器、消息队列等，支持 string、hash、list、zset 等多种数据结构。

#### 三种常见部署模式

1. **主从复制** 一主多从，主节点负责写，数据同步到从节点；从节点只读，分担读请求、备份数据。缺点：主挂了不会自动切换，写无法扩容。
2. **Sentinel（哨兵）** 基于主从，额外部署哨兵进程监控节点。主节点故障时自动选从升主，实现高可用。 ⚠️ 注意：仍然只有一个主节点，数据全量存储，**不能扩容写能力**。
3. **Redis Cluster（分片集群，原生集群）** 多主多从架构，一共划分 16384 个哈希槽，key 通过哈希算法分配到不同主节点，数据分片存放。

- 优点：读写都可以横向扩容，自带故障转移
- 缺点：跨槽位的多 key 命令有限制，运维更复杂

> 最小推荐：3 主 3 从

#### 持久化

- RDB：快照，保存某一刻全部数据，文件小恢复快，可能丢数据。
- AOF：记录每条写命令，安全性高，默认每秒落盘，文件更大。
- 同时开启时，重启优先加载 AOF。

一句话：RDB 是拍照，AOF 是记操作日志。

### PHP

**服务端脚本语言，本身只是解释器，不能独立监听端口接收网络请求。 **PHP-FPM（PHP FastCGI Process Manager）**：PHP 的 FastCGI 进程管理器，是 PHP 用来和 Nginx/Apache 配合的中间程序。

#### 简单流程

Nginx（L7 反向代理）收到用户请求 → 如果是 php 文件 → Nginx 把请求转发给 **php-fpm** → fpm 调用 php 解释器执行代码 → 把页面结果返回给 Nginx，再发给浏览器。

#### 要点

1. Nginx 只负责静态文件、转发请求，**不解析 PHP 代码**
2. php-fpm 维护一组 PHP 工作进程池，进程数量可以配置
3. 通信方式：`unix socket`（本机，快） 或者 `tcp ip:port`（跨机器）
4. 常见参数：`pm.max_children` 最大子进程数，控制并发

一句话总结： **PHP 是解释器，php-fpm 是管理 PHP 进程、接收 Nginx 请求的服务。**

### L4 四层负载均衡（传输层）

基于**IP + 端口**转发，看 TCP/UDP，不解析应用内容。

- 工作层级：传输层（TCP/UDP）
- 识别信息：源 IP、目标 IP、端口
- 代表：LVS、IPVS、Nginx stream、HAProxy mode tcp
- 特点：速度快、开销小；**看不到 HTTP 请求内容**，不能识别域名、url、cookie

### L7 七层负载均衡（应用层）

基于**应用协议内容**转发（HTTP/HTTPS）。

- 工作层级：应用层
- 识别信息：域名、URL、Cookie、请求头、路径
- 代表：Nginx http、HAProxy mode http、Ingress
- 特点：功能丰富，可以按路径 / 域名分流；需要解析协议，性能比 L4 低一点

> 一句话区分： L4：只管 “把包送到哪个端口”； L7：看懂 HTTP 内容，按网站域名、路径分发请求。

* 创建数据库测试的php文件

```b
cat /opt/lnmp/blog/www/db_test.php
<?php
/**
 * MySQL 连接测试脚本 (mysqli 面向过程风格)
 * 若指定数据库不存在则自动创建
 * 使用前请修改下方数据库连接信息
 */

// ========== 请在此处填写你的数据库信息 ==========
$db_host = 'mysql';      // 数据库地址，这里不写127.0.0.1，因为项目是mysql
$db_port = 3306;             // 端口，默认 3306
$db_user = 'root';           // 用户名
$db_pass = '123456';        // 密码
$db_name = 'test';    // 要连接/创建的数据库名
$db_charset = 'utf8mb4';     // 字符集
$db_collation = 'utf8mb4_general_ci';  // 排序规则
// ================================================

mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);

echo "=== MySQL 连接测试 ===\n";
echo "正在尝试连接 {$db_host}:{$db_port} ...\n\n";

try {
    // 第一步：先不指定数据库，连接到 MySQL 服务器本身
    $conn = mysqli_connect($db_host, $db_user, $db_pass, null, $db_port);
    mysqli_set_charset($conn, $db_charset);

    echo "✅ 已连接到 MySQL 服务器\n";
    echo "服务器版本: " . mysqli_get_server_info($conn) . "\n";

    // 第二步：检查目标数据库是否存在
    // 用预处理语句防止 SQL 注入
    $stmt = mysqli_prepare($conn,
        "SELECT SCHEMA_NAME FROM information_schema.SCHEMATA WHERE SCHEMA_NAME = ?"
    );
    mysqli_stmt_bind_param($stmt, 's', $db_name);
    mysqli_stmt_execute($stmt);
    mysqli_stmt_store_result($stmt);

    if (mysqli_stmt_num_rows($stmt) > 0) {
        echo "📦 数据库 [{$db_name}] 已存在，直接使用。\n";
    } else {
        echo "📦 数据库 [{$db_name}] 不存在，正在创建...\n";
        // 注意：CREATE DATABASE 不能用预处理占位符，库名需白名单校验
        if (!preg_match('/^[a-zA-Z0-9_]+$/', $db_name)) {
            throw new Exception("数据库名只允许字母、数字、下划线，出于安全禁止特殊字符。");
        }
        $sql = "CREATE DATABASE `{$db_name}` DEFAULT CHARACTER SET {$db_charset} COLLATE {$db_collation}";
        mysqli_query($conn, $sql);
        echo "✅ 数据库 [{$db_name}] 创建成功。\n";
    }
    mysqli_stmt_close($stmt);

    // 第三步：选择该数据库
    mysqli_select_db($conn, $db_name);
    echo "🔌 已切换到数据库 [{$db_name}]\n\n";

    // 第四步：执行验证查询
    $result = mysqli_query($conn, "SELECT VERSION() AS version, NOW() AS server_time");
    $row = mysqli_fetch_assoc($result);
    echo "数据库版本: " . $row['version'] . "\n";
    echo "服务器时间: " . $row['server_time'] . "\n";

    $db_result = mysqli_query($conn, "SELECT DATABASE() AS db");
    $db_row = mysqli_fetch_assoc($db_result);
    echo "当前数据库: " . $db_row['db'] . "\n";

    mysqli_free_result($result);
    mysqli_free_result($db_result);

} catch (mysqli_sql_exception $e) {
    echo "\n❌ 数据库错误！\n";
    echo "错误编号: " . $e->getCode() . "\n";
    echo "错误信息: " . $e->getMessage() . "\n";
    exit(1);
} catch (Exception $e) {
    echo "\n❌ 其他错误！\n";
    echo "错误信息: " . $e->getMessage() . "\n";
    exit(1);
} finally {
    if (isset($conn) && $conn) {
        mysqli_close($conn);
        echo "\n连接已关闭。\n";
    }
}
```

## 7.redis节点

* 本案例中redis用于保持session信息
  * 原因：两个php-fpm的session会保留在本地，所以在发生负载均衡的时候，提交的session会消失。
  * 解决办法：将session保存在redis中，让php-fpm从redis中读取session。
  * 相关目录读取办法：挂载redis的数据存储在哪里，配置存储在哪里。去dockerhub配置查找

```b
#===========redis========
```

### 排错思路

#### 错误原因

* 在第一次通过Dockerfile生成php的时候，AI生成的代码中没有pdo_mysql导致出现could not find driver的报错

* 把pdo_mysql添加进Dockerfile之后，删除镜像使用run.sh新建容器。
  * 通过命令行方式查看，发现下载完成pdo_mysql
  * 通过指针网页查看，发现并不存在pdo_mysql
* 原因在于，创建/opt/lnmp/blog/php文件夹的时候，采用的是手动挂载的形式，导致使用run.sh产生的容器依旧读取已经保存在宿主机的内容

#### 解决方法

* 删除/opt/lnmp/blog/php中的全部文件，然后重新启动run.sh文件
* 重新手动挂载php的配置文件
* 如果还是存在错误
  * 浏览器缓存
  * 重启run.sh
